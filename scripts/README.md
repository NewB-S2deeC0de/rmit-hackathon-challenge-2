# Scripts — Shared Development & Verification Scripts

## 1. Danh sách Scripts
* `npm test`: Chạy toàn bộ 21 unit tests của module PCF.
* `npm run check`: Kiểm tra TypeScript strict type checking không lỗi cú pháp.
* `scripts/test-all.sh`: Chạy kiểm thử tự động trên cả module `backend/reporting/` và `src/`.
